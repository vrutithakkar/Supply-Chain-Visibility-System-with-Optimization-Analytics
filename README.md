# Supply Chain Visibility System with Optimization Analytics

**A Power BI Data Analytics Project | Infosys Springboard Internship**

## 📌 Project Overview

The **Supply Chain Visibility System with Optimization Analytics** is a data analytics and business intelligence project developed as part of my Infosys Springboard Data Analytics Internship.

The project uses Microsoft Power BI to analyze supply chain operations and present meaningful insights through interactive dashboards. It focuses on inventory management, sales performance, shipments, delivery operations, warehouse efficiency, and supplier reliability.

The goal is to transform raw data into actionable insights, monitor key performance indicators (KPIs), identify operational inefficiencies, and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze supply chain and sales performance.
- Monitor inventory value, product performance, and inventory turnover.
- Evaluate delivery timelines and shipment performance.
- Analyze warehouse efficiency and supplier reliability.
- Develop interactive dashboards to track important KPIs.
- Identify potential opportunities for operational improvement.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX (Data Analysis Expressions)** — KPI calculations and analytical measures
- **Data Modeling** — Relationships between supply chain data tables

## 📊 Dashboard Modules

The project includes seven dashboard views:

1. **Executive Overview** — Overall business performance and key supply chain KPIs.
2. **Inventory Analysis** — Inventory value, product performance, and inventory turnover.
3. **Delivery Analysis** — Delivery performance and fulfillment-related metrics.
4. **Shipment and Transportation Analysis** — Shipment trends and transportation costs.
5. **Warehouse Efficiency Analysis** — Warehouse performance and operational indicators.
6. **E-commerce Sales Dashboard** — Revenue, sales, and product-related insights.
7. **Dashboard Performance Optimization** — Dashboard performance and optimization-related analysis.

## 📈 Key Performance Indicators (KPIs)

The dashboards cover metrics such as:

- Total Revenue
- Total Orders
- Quantity Sold
- Inventory Value
- Inventory Turnover
- Total Shipments
- Shipping Cost
- On-Time Delivery Rate
- Order Fulfillment Rate
- Supplier Reliability
- Warehouse Efficiency
